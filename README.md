# poptools
Prince of Persia The Sands of Time Trilogy Mod Tools

This repository is a collection of **modding tools for the _Prince of Persia: The Sands of Time_ trilogy**:

- The Sands of Time (2003)  
- Warrior Within (2004)  
- The Two Thrones (2005)

The purpose of this project is to **centralize historical and modern tools** used for modding, reverse engineering, and technical analysis of the trilogy, preserving material that is often scattered across old forums, dead links, and personal archives.

---

## ⚠️ Important Notice

This is **not a collection of original tools created by the repository maintainer**.  
Most of the tools included here were **developed by other members of the community**, sometimes many years ago, and are re-uploaded **for preservation, research, and ease of access**.

👉 **All credit goes to the original authors**.  
If you are the author of any tool included here and would like to:
- be credited differently,
- add additional information,
- or request removal of your work,

please open an *Issue* or contact the maintainer.

---

## 🧰 Contents

Depending on the current state of the repository, this collection may include tools for:

- Extracting and analyzing game files (`.bf`, `.bin`, `.wow`, `.wol`, etc.)
- Editing assets such as levels, textures, and animations
- Analyzing demos and prototype builds
- Utilities for **PC, PlayStation 2, and Xbox** versions
- Experimental or undocumented tools

Whenever possible, each tool is accompanied by:
- a short description,
- usage notes,
- references to the original author or source.

---

## 🎯 Project Goals

- Preserve historical modding tools for Prince of Persia
- Make research and experimentation easier
- Support technical analysis of the trilogy
- Encourage new modding and reverse engineering efforts

This repository **does not contain copyrighted game assets**, only **tools intended to assist modding and research**.
